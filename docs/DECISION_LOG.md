## 2026-05-24 — Adopt Lightweight Product Development Process

**Decision:** Use a lightweight PM loop for meaningful Wardrub features: Idea → PRD → Review → Implementation Plan → Build → QA → Learn.

**Why:** Wardrub has multiple tempting directions: VTON, avatar generation, magazine feed, chatbot, Chrome extension, shopping recommendations. Without a product process, we risk building disconnected experiments instead of a coherent product.

## 2026-05-24 — Draft Magazine Feed as Product Bet

**Decision:** Create a PRD for a magazine-style personalized feed built from clothes the user already owns.

**Current status:** Draft for Hardik review.

**Key product hypothesis:** Users will find daily value in curated outfit recommendations from their own wardrobe, even before photorealistic try-on is perfect.
